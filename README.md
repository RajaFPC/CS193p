# CS193p - iOS Development with SwiftUI

A hands-on project repository for learning iOS app development using **SwiftUI** and **Swift**.

## 📚 About

This repository contains practice projects and exercises from Stanford's CS193p course, focusing on modern iOS development with SwiftUI. It's designed to progressively build skills in:

- SwiftUI fundamentals (Views, State, Binding)
- App architecture and MVVM patterns
- Navigation and data flow
- Networking and APIs
- Local storage and persistence
- Advanced UI patterns

## 🚀 Getting Started

### Prerequisites
- **macOS** 13.0 or later
- **Xcode** 14.0 or later
- **Swift** 5.7 or later
- Basic Swift programming knowledge recommended

### Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/RajaFPC/CS193p.git
   cd CS193p

1. Verify SSH works:
ssh -T git@github.com
2. Clone existing repo (SSH):
git clone git@github.com:owner/repo.git
3. For a new local project -> create remote and push:
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin git@github.com:YOUR_USERNAME/REPO.git
git push -u origin main
4. Convert an HTTPS remote to SSH:
git remote get-url origin
git remote set-url origin git@github.com:OWNER/REPO.git

Notes:

• Use the git@github.com:owner/repo.git URL every time to avoid credential prompts.
• If ever prompted, run ssh-add ~/.ssh/id_ed25519 (or ensure your ~/.ssh/config + keychain is set as done).
