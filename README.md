# CS193p - iOS Development with SwiftUI

A hands-on project repository for learning iOS app development using **SwiftUI** and **Swift**.

## 📚 About

This repository contains practice projects and exercises from Stanford's CS193p course, focusing on modern iOS development with SwiftUI. It's designed to progressively build skills in:

- SwiftUI fundamentals (Views, State, Binding)
- App architecture and MVVM patterns
- Navigation and data flow
- Networking and APIs
- Local storage and persistence
- Advanced UI patterns

## 🚀 Getting Started

### Prerequisites
- **macOS** 13.0 or later
- **Xcode** 14.0 or later
- **Swift** 5.7 or later
